 KyungsinLPR 소켓 명령 연동 가이드 (외부 프로그램용)
================================================================
 외부 프로그램이 LPR(차번인식 프로그램)에 TCP 소켓으로 명령을 보내
 - 차량번호 인식을 요청하고
 - 차단기(게이트)를 제어하고
 - 전광판에 문구를 표시할 수 있습니다.

----------------------------------------------------------------
 1. 접속 방법
----------------------------------------------------------------
 - 프로토콜 : TCP (클라이언트가 LPR에 접속)
 - LPR IP   : 현장 LPR PC의 IP
 - 포트
     · 30000 : 입차 서버  (차번인식 요청 CAPTURE 포함, 명령 전반)
     · 40000 : 출차 서버  (요금계산기용, 명령 전반)
   ※ 게이트/전광판/열림고정 명령은 두 포트 모두 처리됩니다.
   ※ 차번인식(CAPTURE) 요청은 30000(입차)에서만 처리됩니다.
 - 연결 유지 : 응답(차번 등)을 받으려면 연결을 끊지 말고 계속 열어 둘 것.
 - 문자 인코딩 : 명령어/숫자는 ASCII. (전광판 한글 문구 인코딩은 LPR 설정과 맞출 것)

----------------------------------------------------------------
 2. 메시지 형식(공통)
----------------------------------------------------------------
 - 필드 구분자 : '^' (캐럿)
 - 감싸기(선택) : STX(0x02) ... ETX(0x03) 로 감싸도 됨(LPR이 양쪽 다 처리).
   단, 아래 'CAPTURE'만은 반드시 STX+CAPTURE+ETX "정확히" 보내야 함.

----------------------------------------------------------------
 3. 차량번호 인식 요청  ★핵심
----------------------------------------------------------------
 [보내는 값] (30000 포트)
     카메라1 :  0x02 CAPTURE  0x03   또는   0x02 CAPTURE1 0x03
     카메라2 :  0x02 CAPTURE2 0x03
       · CAPTURE  = 02 43 41 50 54 55 52 45 03        (9바이트,  카메라1, 기존 호환)
       · CAPTURE1 = 02 43 41 50 54 55 52 45 31 03     (10바이트, 카메라1)
       · CAPTURE2 = 02 43 41 50 54 55 52 45 32 03     (10바이트, 카메라2)
     (앞뒤에 다른 문자/공백/^ 가 붙으면 무시됨. "정확히" 위 바이트만)

 [동작]
     지정한 카메라(1 또는 2)로 즉시 촬영 → 차번 인식 수행.

 [결과 받기]
     CAPTURE에 대한 즉시 응답은 없습니다.
     인식이 끝나면(보통 수백 ms 뒤) 차번 검출 메시지가 비동기로 전송됩니다.
     연결을 유지한 채 수신 대기하세요.

 [결과가 오는 포트]  ★중요
     검출 메시지는 "각 카메라의 입/출구 설정"에 따라 나갑니다:
       · 입구용 카메라 결과 → 30000 (입차 서버)
       · 출구용 카메라 결과 → 40000 (출차 서버)
     카메라1·2가 입구/출구로 나뉜 경우, 30000·40000 두 포트를 모두 열어두고 수신하세요.
     (CAPTURE1/CAPTURE2 명령은 30000 포트로 보냅니다.)

     ▶ 조건: LPR 환경설정의 "입출차 처리옵션 > 자료전송(SendData)"이 켜져 있어야
       차번이 되돌아옵니다. (꺼져 있으면 인식은 하지만 응답이 안 옴)

     ▶ 검출 메시지 형식 (LPR 환경설정 socketformat 에 따라 택1):
         · Kukje  :  !{채널}#{차번}#{파일명}#{yyyyMMdd}#{HHmmss}
                     예)  !CH01#12가3456#CH01_...jpg#20260807#121530
         · Amano/Nexpa :  {채널}#{차번}#{yyyyMMdd}\{파일명}
       (STX/ETX 감쌈 여부는 LPR [CAMERA] SendStxEtx 설정을 따름)
       인식 실패 시 차번 자리에 "No_Detection" 이 올 수 있음.

----------------------------------------------------------------
 4. 차단기(게이트) 제어
----------------------------------------------------------------
 [방법 A] 입출구 지정 개방
     보냄 :  CALC^GATEOPEN^ENTRANCE      (입구 개방)
             CALC^GATEOPEN^EXIT          (출구 개방)
     동작 :  해당 방향으로 설정된 LPR의 게이트를 개방.

 [방법 B] 릴레이 포트 직접 제어 (원격 접점)
     보냄 :  MNG^GateOpen^{포트}         (예: MNG^GateOpen^1)
             MNG^GateClose^{포트}        (예: MNG^GateClose^1)
     동작 :  지정 릴레이 포트를 개방(약 1초 펄스).
     응답 :  GateOpen^   /   GateClose^   (LPR이 회신)
     ※ {포트} = 릴레이 보드(게이트) 출력 포트 번호 (현장 게이트포트, 예 1~4)
     ※ 해당 게이트가 "열림고정" 상태면 펄스를 생략함.

 [방법 C] 차단기 열림고정(상시 개방) 설정/해제
     보냄 :  MNG^OpenFix^{포트}^a        (열림고정 ON  - 상시 열림 유지)
             MNG^OpenFix^{포트}^b        (열림고정 해제)
     응답 :  GateClose^
     ※ 'a' = 고정 ON, 'b' = 고정 해제.

----------------------------------------------------------------
 5. 전광판 문구 표시
----------------------------------------------------------------
     보냄 :  CALC^DISPLAY^{1행문구}^{2행문구}
     예   :  CALC^DISPLAY^주차요금^2,000원
     동작 :  출구용으로 설정된 LPR의 전광판에 1행/2행 표시.
     해제 :  CALC^CANCEL^...   또는   CALC^FINISH^...  (표시 종료)
     ※ 색상은 LPR 내부 기본값 적용. 문구는 표시 길이에 맞게 잘릴 수 있음.

----------------------------------------------------------------
 6. 연결 유지(keepalive)  - 선택
----------------------------------------------------------------
     보냄 :  Alive        또는   !live   또는   OK
     동작 :  LPR이 연결 살아있음으로 처리. '!live' 를 보내면 LPR이 '!live' 회신.
     ※ 장시간 무통신 시 주기적으로(예: 30초) 보내면 연결 안정에 도움.

----------------------------------------------------------------
 7. 사용 예 (차번 인식)
----------------------------------------------------------------
     1) LPR IP의 30000 포트로 TCP 접속 (연결 유지)
     2) 02 43 41 50 54 55 52 45 03  (STX CAPTURE ETX) 전송
     3) 연결을 유지한 채 수신 대기
     4) 예) "!CH01#12가3456#...#20260807#121530" 수신 → 차번 "12가3456" 파싱

----------------------------------------------------------------
 8. 주의사항
----------------------------------------------------------------
 - 별도 인증/암호화가 없습니다. LPR과 외부 프로그램은 "같은 내부망"에서만
   연결하고, 방화벽으로 30000/40000 포트 접근을 제한하세요.
 - 차번인식은 CAPTURE/CAPTURE1(카메라1), CAPTURE2(카메라2)로 각각 요청합니다(30000 포트).
 - 차번 응답은 "자료전송(SendData)" 옵션이 켜져 있어야 옵니다.
 - 응답 수신 포트는 각 카메라의 입/출구 설정을 따릅니다(입구=30000, 출구=40000).
 - 명령은 대소문자를 정확히 지켜서 보내세요 (CAPTURE, GateOpen 등).
